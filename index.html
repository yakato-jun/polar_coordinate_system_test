極座標モデルの解剖: ρ, α, β が v_x / ω_z にどう効くか

軌跡ビュー

現在の内訳 (指令 = 各項の総和)

① 誤差項 ρ, α, β の時系列 — 何が大きくて何が小さいか

② v_x の構成: v_raw = k_ρ·ρ と v_cmd (クリップ後)

③ ω_z の寄与分解 ★ — 各項が各タイミングでどう効いているか

読み方: k_ρ·ρ → v_x を生む唯一の項。 k_α·α → ω_z を通じて「ゴール方向に頭を向ける」仕事。 k_β·β → ω_z を通じて「ゴール姿勢に合わせる」仕事。

軌跡ビューの見方:
赤実線+赤矢印 = 通常の極座標モデル (β項あり)
灰色破線+灰色矢印 = ゴースト(k_β=0 にした場合の挙動。β項が何をしているかが一目で分かる比較)
緑の破線 = ゴール目標姿勢の延長線 (通常軌跡の向きが最後にこれに揃う)

k_β を強くすると何が起きるか:
・スライダーで k_β の絶対値を上げる → ゴール手前から「姿勢が合う形」で進入しようとする
・ゴーストと通常軌跡の乖離が大きくなる = β項の仕事量が大きい
・k_β = 0 (= ゴースト) では姿勢誤差が残ってゴール到着する
